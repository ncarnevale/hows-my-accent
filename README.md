# How's My Accent

"How's My Accent" is a lightweight AI-assisted web app for English speakers learning Latin American Spanish pronunciation. Record yourself reading a passage, then get feedback on accuracy and which sounds to practice.

## Live Site

http://tentsandtrees.cool/

## Tech Stack

- Next.js (App Router)
- React + TypeScript
- OpenAI (Whisper)
- Tailwind CSS

## Running locally

```bash
npm install
npm run dev
```

Create a `.env.local` file with:

```
OPENAI_API_KEY=...
```
